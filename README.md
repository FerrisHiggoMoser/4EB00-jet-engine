# 4EB00 Jet Engine

Cycle analysis of a turbojet in MATLAB for the 4EB00 special topic (group 5: Gasoline, AF 71.25, P3/P2 = 7).

- `Assignment.m` - the script. Run it from this folder, it needs the `General` folder next to it.
- `General/` - NASA functions and database from the course.
- `Groep005_combustor_section.docx` - report template with the combustor section filled in.
